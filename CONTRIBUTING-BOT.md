# Инструкция для робота-редактора

Этот файл читает облачный агент, который раз в три дня пополняет банк заданий. Человеку он тоже полезен как справочник по формату.

## Что делать за один запуск

1. Добавить **8 новых ситуационных задач** в `js/data/situational.js` (в массив `QUESTION_DATA.situational`, перед закрывающей `];`).
2. Добавить **6 новых вопросов по правилам** в `js/data/rules.js` (в массив `QUESTION_DATA.rules`).
3. Добавить **6 новых слов** в `js/data/vocabulary.js`.
4. Проверить синтаксис: `node scripts/check-data.js` должен завершиться без ошибок.
5. Закоммитить в `main` с сообщением вида `Контент: +8 ситуаций, +6 правил, +6 слов (неделя N)`.

Не трогать другие файлы. Не менять существующие вопросы, кроме исправления явной фактической ошибки (тогда упомянуть это в коммите).

## Формат вопроса (ситуации и правила)

```js
q("027",                                    // id: следующий свободный трёхзначный номер в файле
  "Spørsmål på enkel norsk bokmål?",        // prompt_no
  "Вопрос по-русски?",                       // prompt_ru
  [
    ["Riktig svar", "Правильный ответ"],     // ПЕРВЫЙ вариант всегда правильный, без пояснения
    ["Feil 1", "Неверный 1", "Hvorfor dette er feil (1–2 setninger).", "Почему это неверно (1–2 предложения)."],
    ["Feil 2", "Неверный 2", "Hvorfor dette er feil.", "Почему это неверно."],
    ["Feil 3", "Неверный 3", "Hvorfor dette er feil.", "Почему это неверно."]
  ],
  "Forklaring på norsk: hvilken regel gjelder og hvorfor.",
  "Объяснение по-русски.",
  "Совет по-русски: как запомнить или на что смотреть, чтобы не ошибиться.")
```

**Обязательно:** у каждого неверного варианта 3-й и 4-й элементы — объяснение, почему именно этот вариант неверен (норвежский и русский). Сайт показывает его после ответа: «Du svarte: … — почему неверно», затем «Riktig svar: … — обоснование». Не повторяй в нём общее объяснение вопроса, а говори конкретно про ошибку в выбранном варианте (какое правило или число перепутано).

В `situational.js` второй аргумент после id — картинка: `scene({...})` или `null`. Схема:

```js
scene({
  you: { from: "south", to: "north" },       // ты — машина A; to: north = прямо, west = налево, east = направо
  others: [{ from: "east", to: "west" }],    // другие машины B, C…; kind: "bike" для велосипедиста
  signs: { south: "yield" },                 // знак на стороне: yield | priority | stop
  lights: { south: "green", east: "red" },   // светофоры
  roundabout: true                           // круговое движение
})
```

Для ситуаций на прямой дороге есть второй тип схемы, `road({...})` — используй его вместо перекрёстка, когда в вопросе нет перекрёстка:

```js
road({ bus: true, limit: 50 })   // автобус с поворотником выезжает с остановки, A сзади
road({ crossing: true })         // пешеходный переход, пешеход справа
road({ narrow: true })           // узкая дорога, разъезд (møteplass) на стороне A, B навстречу
road({ exit: "parking" })        // A выезжает с парковки на дорогу; exit: "gatetun" — из жилой зоны
road({ tcross: true })           // T-перекрёсток: боковая дорога справа, B выезжает из неё
road({ bikeLane: true })         // велополоса справа, A поворачивает направо, велосипедист B едет прямо
road({ overtake: true })         // машина B впереди с левым поворотником объезжает велосипедиста, A сзади
road({ night: true })            // ночь, пешеход в тёмном идёт по левой обочине навстречу
road({ truck: true, tcross: true }) // грузовик впереди сместился влево перед правым поворотом
road({ tram: true })             // трамвай на остановке, пассажиры переходят к тротуару
```

В `scene({...})` у других машин можно задать вид: `kind: "bus" | "truck" | "tram" | "emergency" | "bike"` — если в вопросе автобус, грузовик, трамвай или машина с мигалкой, на схеме должен быть именно он. Пешеход на переходе рукава: `peds: ["east"]`.

Картинка обязана соответствовать тексту вопроса: не ставь схему перекрёстка к вопросу про автобус или погоду. Если подходящей схемы нет — ставь `null` (автомагистраль, погода, усталость, оборудование).

## Вопросы с несколькими правильными ответами

Как на teoriprøven («Velg alle riktige»). Помощник `qm()` есть в `rules.js` и `situational.js` (в situational второй аргумент — картинка). У каждого варианта третий элемент — `true`/`false`; правильных должно быть 2 или 3 из 4; `why` пишется только у неверных. В конце вопроса добавляй «Velg alle riktige.» / «Выбери все верные.»:

```js
qm("m15", "Spørsmål? Velg alle riktige.", "Вопрос? Выбери все верные.", [
  ["Riktig 1", "Верный 1", true],
  ["Riktig 2", "Верный 2", true],
  ["Feil 1", "Неверный 1", false, "Hvorfor feil.", "Почему неверно."],
  ["Feil 2", "Неверный 2", false, "Hvorfor feil.", "Почему неверно."]
],
"Forklaring.", "Объяснение.", "Совет.")
```

Id у таких вопросов: `m` + номер (m01, m02, …). В каждом запуске из добавляемых вопросов делай 1–2 такими.

## Формат слова

```js
w("057", "ord på norsk", "перевод", "Eksempelsetning på norsk.", "Перевод примера.", "Группа")
```

Группы: Основное, Приоритет, Действия, Машина, Условия.

## Требования к содержанию

- Источник истины: vegtrafikkloven, trafikkreglene, skiltforskriften, teoribok Statens vegvesen. Если не уверен в факте, не пиши вопрос.
- Ставки штрафов — с 15.02.2026: телефон/красный/vikeplikt/дистанция/обгон 10 750 kr и 3 балла; без света 4 100 kr; скорость в зонах ≤60: +5 = 1 250, +10 = 3 350, +15 = 5 950 и 2 балла, +20 = 8 650 и 3 балла, +25 = 13 450 и 3 балла, от +26 лишение; в зонах ≥70: +5 = 1 250, +10 = 3 350, +15 = 5 350, +20 = 7 450 и 2 балла, +25 = 10 100 и 3 балла, от +36 лишение. 8 баллов/3 года = 6 месяцев без прав; первые 2 года баллы удваиваются.
- Ученики взрослые: правила для 16–18-летних (øvelseskjøring, ledsager) не нужны.
- Норвежский: простой bokmål уровня A2–B1, без сложных конструкций. Русский перевод точный, не дословный.
- Неверные варианты должны быть правдоподобными: типичные заблуждения, а не абсурд.
- Не повторять темы, которые уже есть в файле: перед написанием прочитай существующие вопросы.
- Разнообразие: перекрёстки, круг, пешеходы, велосипедисты, автобус, трамвай, автомагистраль, тоннель, зима, парковка, прицеп, ДТП, алкоголь, усталость, дети в машине, животные.

## Факты, на которых уже были ошибки (проверено по Lovdata)

- Велосипедисты в Норвегии **не обязаны** ехать по велополосе или велодорожке.
- Сплошную осевую (sperrelinje) **нельзя** пересекать ради обгона велосипедиста или мопеда — исключения нет.
- 1,5 м до велосипедиста при обгоне — **рекомендация**, закон требует «god avstand».
- Временные знаки при дорожных работах в Норвегии **жёлтые**, не оранжевые.
- Piggdekkgebyr только в Oslo, Bergen, Trondheim (Stavanger и Kristiansand отменили в 2023).
- Парковка на двусторонней дороге только справа по ходу; на односторонней — с обеих сторон.
- Знак «innkjøring forbudt» — красный круг с белой полосой (не белый с красной каймой).
