# Førerkort-trener — контекст проекта для Claude

Общаться с пользователем по-русски. Пользователь не программист; объяснять по шагам, без жаргона, команды давать готовыми блоками.

## Что это

Сайт-тренажёр к теории на водительские права класса B в Норвегии для пользователя, его девушки и круга друзей. Задания на норвежском с переводом на русский, разбор ошибок, экзамен как teoriprøven. Пользователь взрослый (старше 18): правила для 16–18-летних (øvelseskjøring, ledsager по возрасту) в контент не включать.

- Сайт: https://veelltman.github.io/F-rekort-asisnet/ (GitHub Pages, ветка `main`, обновляется через ~1 мин после push)
- Репозиторий: https://github.com/Veelltman/F-rekort-asisnet
- Сервер: https://forerkort-trener.velltman.workers.dev (Cloudflare Worker, папка `worker/`, KV `USERS`; wrangler залогинен на этой машине)
- Робот-редактор: routine `trig_01Ur86axpC8vnp75S2iwextm`, каждый день 09:00 UTC (12:00 Киев) читает `CONTRIBUTING-BOT.md`, добавляет +8 ситуаций, +6 правил, +6 слов, гоняет `node scripts/check-data.js`, коммитит в main. Его коммиты стоит проверять на факты (уже была ошибка про велополосу).
- Код приглашения для регистрации на сайте: `prøve`. Первый зарегистрированный = владелец.
- «Учитель» (Claude API) пользователь решил не подключать: ключ на сервере не задан, друзьям учитель закрыт по замыслу. Не предлагать снова, если не спросит.

## Стек и запуск

Статический сайт: vanilla JS, без сборки. Локально: `npx -y serve -l 5173 .` (конфиг в `.claude/launch.json`, имя `site`). Проверка данных: `node scripts/check-data.js` — запускать после любых правок в `js/data/`.

Git identity не настроен глобально — коммитить так:
`git -c core.autocrlf=false -c user.name="malet" -c user.email="malets239@gmail.com" commit -m "..."` затем `git push origin main`.

## Структура

- `index.html`, `css/styles.css` — оболочка, дизайн (асфальт + жёлтая разметка, шрифты Unbounded/Golos Text, тёмная тема, мобильная нижняя навигация, PWA-манифест и `sw.js`)
- `js/quiz-engine.js` — движок: выбор → «Sjekk» → объяснение; стрелки ← →; обзор всех вопросов в конце; режим экзамена (`exam: true`, 45 вопросов, 90 мин, ≤7 ошибок)
- `js/app.js` — экраны: главная (круг друзей, задание дня, экзамен, темы), тема, квиз, ошибки, лексика, вход
- `js/storage.js` — localStorage, профили, облачный профиль; `js/cloud.js` — API сервера
- `js/data/signs-catalog.js` — 155 знаков (картинки в `img/signs/`), `signs.js` генерирует задания трёх типов
- `js/data/situational.js` — ручные ситуации + функция `scene()` (схемы перекрёстков, правостороннее движение, круг против часовой)
- `js/data/rules.js` — правила; ставки forenklet forelegg с 15.02.2026 (индексируются ежегодно в феврале — при смене года пересверить с tryggeveier.no / lovdata.no)
- `js/data/generated.js` — генераторы: движок приоритета для перекрёстков и числовые задачи (штрафы, баллы, дистанции, прицеп)
- `js/data/vocabulary.js` — лексика (официальные термины: trafikkskole, trafikklærer, tettbygd strøk)
- `CONTRIBUTING-BOT.md` — формат данных и требования к контенту (для робота и для людей)

## Проверенные факты (не менять без источника)

Штрафы 2026: телефон/красный/vikeplikt/дистанция/обгон 10 750 kr + 3 балла; без света 4 100 kr; скорость ≤60: +5 1 250, +10 3 350, +15 5 950 (2 б.), +20 8 650 (3 б.), +25 13 450 (3 б.), от +26 лишение; ≥70: +5 1 250, +10 3 350, +15 5 350, +20 7 450 (2 б.), +25 10 100 (3 б.), от +36 лишение. 8 баллов/3 года → 6 мес.; первые 2 года баллы ×2. Промилле 0,2. Ближний свет всегда. Дети <135 см в кресле; за ремень пассажира ≥15 лет отвечает он сам. Стоянка: 5 м до перехода/перекрёстка, 20 м от знака остановки. Зимой 3 мм (1 ноя — первое воскресенье после 2. påskedag; север 16 окт — 30 апр), шипы до первого понедельника после 2. påskedag. Piggdekkgebyr: Oslo, Bergen, Trondheim (Stavanger отменил в 2023). Велосипедисты НЕ обязаны использовать велополосу. Парковка только справа на двусторонней дороге. Автобус из остановки пропускать при лимите ≤60. Категория B: прицеп ≤750 кг или сумма ≤3 500 кг.
