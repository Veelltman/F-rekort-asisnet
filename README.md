# Førerkort-trener — тренажёр к теории на права (Норвегия, класс B)

Сайт-тренажёр: задания на норвежском с переводом на русский, мгновенная проверка, разбор ошибок и режим повторения слабых мест. Работает целиком в браузере, без сервера и регистрации. Прогресс хранится в `localStorage` этого браузера, отдельно для каждого профиля.

## Как открыть

Вариант 1: открыть `index.html` двойным кликом.

Вариант 2: локальный сервер (нужен Node.js):

```bash
npx -y serve -l 5173 .
```

и открыть http://localhost:5173.

## Профили

Кнопка с именем в шапке. Каждый профиль хранит свой прогресс, ошибки и результаты задания дня. Профили живут в одном браузере: если заниматься с разных телефонов, у каждого будет свой набор.

## Задание дня

20 вопросов, одинаковых для всех профилей в один день (набор зависит только от даты). Результат записывается один раз — первая попытка. На главной видно, кто как прошёл.

## Что внутри

| Модуль | Файл | Формат |
|---|---|---|
| Каталог знаков (155 шт.) | `js/data/signs-catalog.js` | название, перевод, тип, объяснение, совет |
| Генератор заданий по знакам | `js/data/signs.js` | «что означает», «найди знак», «тип знака» + разметка |
| Ситуационные задачи | `js/data/situational.js` | схема перекрёстка + варианты |
| Правила и штрафы | `js/data/rules.js` | ставки 2026 (с 15.02.2026) |
| Лексика | `js/data/vocabulary.js` | флеш-карточки |

Картинки знаков: `img/signs/`. Задания по знакам генерируются автоматически: у каждого знака стабильный id для статистики, а неверные варианты каждый раз подбираются заново из знаков того же типа, поэтому одно и то же задание не выглядит одинаково дважды.

## Как добавить знак

1. Положи картинку в `img/signs/`.
2. Добавь строку в `LIST` в `js/data/signs-catalog.js`:

```js
e("имя-файла.png", "fare", "Norsk navn", "Русское название",
  "Forklaring på norsk.", "Объяснение по-русски.",
  "Совет при ошибке (необязательно)", "группа (необязательно)")
```

Тип: `fare`, `vikeplikt`, `forbud`, `pabud`, `opplysning`, `underskilt`. Группа нужна, если несколько знаков означают одно и то же (чтобы они не попадали друг другу в варианты ответов). Задания появятся автоматически.

## Как добавить вопрос по правилам или ситуацию

В `rules.js` и `situational.js` первый вариант в списке всегда правильный, при показе варианты перемешиваются.

```js
q("045", "Spørsmål på norsk?", "Вопрос по-русски?", [
  ["Riktig svar", "Правильный ответ"],
  ["Feil 1", "Неверный 1"],
  ["Feil 2", "Неверный 2"],
  ["Feil 3", "Неверный 3"]
], "Forklaring.", "Объяснение.", "Совет при ошибке.")
```

Схема для ситуаций: `scene({ you: { from: "south", to: "north" }, others: [{ from: "east", to: "west" }], signs: { south: "yield" }, roundabout: true })`. Ты всегда машина A. Знаки: `yield`, `priority`, `stop`.

## Сброс прогресса

Внизу экрана «Ошибки»: «Сбросить прогресс этого профиля».

## Важно

Учебное пособие, не официальный материал Statens vegvesen. Ставки штрафов индексируются каждый год (обычно в феврале); если год сменился, сверь цифры в `rules.js` с tryggeveier.no или lovdata.no.
